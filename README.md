# Portfolio

Personal portfolio built with React and Vite.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Deployment

Pushes to `main` are automatically built and deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.

After the first push, open the repository's **Settings → Pages** and set **Source** to **GitHub Actions**. The site will be available at:

`https://madlengeorgieva.github.io/Portfolio/`
